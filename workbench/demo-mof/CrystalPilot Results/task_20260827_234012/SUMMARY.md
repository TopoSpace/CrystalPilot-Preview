# 铜 MOF 单晶结构解析摘要

## 结论

- 最终空间群：**C222(1)**（标准符号 `C 2 2 21`，No. 20，Sohncke 空间群）。
- 晶胞：`a = 15.7900 Å`，`b = 32.3100 Å`，`c = 11.8600 Å`，`α = β = γ = 90°`，`V = 6050.67 Å³`。
- 自动判群给出的近邻候选 C222、Cmm2、C2mm、Cmmm 均进行了独立电荷翻转试解，全部未能得到结构；只有 C222(1) 收敛，电荷翻转图相关系数为 0.953。因此最终采用 C222(1)。
- 数据统计：`d_min = 0.693 Å`，独立反射 8198 个，`R_int = 0.024`，完整度 86.1%。

## 精修指标

- `R1 [强反射] = 0.1021`（7870 个强反射）
- `R1 [全部数据] = 0.1037`
- `wR2 = 0.2912`
- `GooF = 0.948`
- 参数数 324；差值电子密度峰/谷为 `+0.72 / -0.98 e Å⁻³`。
- 自动综合置信度：**80.6/100，high（高）**。
- 使用了溶剂掩膜：2 个孔洞，合计约 375.6 e/晶胞，溶剂可及体积约占晶胞 31.7%。

## Cu 配位与骨架

对 CIF 中对称等价原子去重后，Cu1 的实际配位数为 **5**，Cu–O 距离为：

- Cu1–O3：1.8668 Å
- Cu1–O4：1.9153 Å
- Cu1–O2：1.9336 Å
- Cu1–O1：1.9444 Å
- Cu1–O5：2.3426 Å

最大的两个 O–Cu–O 角为 168.40° 和 164.83°，Addison `τ5 = 0.059`，表明 Cu 为明显的**畸变四方锥五配位**，而非八配位。O1/O2/O4 为羧酸基 O 位点；O3 和较长轴向的 O5 均为 μ2-桥联 O 位点，Cu–O3–Cu 与 Cu–O5–Cu 角分别为 135.92° 和 96.04°。O3/O5 的质子化状态仅凭当前模型不能唯一确定。最近的 Cu···Cu 距离为 3.4608 和 3.4829 Å。Cu(II)–O 键价和为 2.287，支持 Cu(II) 价态。连接性分析给出三维 MOF 骨架。

自动报告中的唯一警报把 Cu 记为 CN=8；复核表明这是特殊位置 O 原子在生成对称等价接触时被重复计数所致，去重后的 CN=5 和四方锥几何是合理结果。

## 质量与使用限制

- R1 约 10.2%，处于多孔/无序 MOF 可接受范围的边缘，wR2 偏高；主要限制来自较低完整度、大孔洞无序溶剂以及若干高 ADP 碳位点，尤其 C33X（`Ueq = 0.3423 Å²`）。该模型适合确定空间群、金属配位和骨架拓扑，但用于发表前仍建议结合化学组成对无序片段施加约束并复核原子类型。
- 当前输入只提供 C/Cu/O 原子类型；自动解释也提示 C/N 区分不能由该模型单独解决。因此 CIF 中的经验式 `C244 H160 Cu8 O32`（不含被掩膜溶剂）应视作当前模型式，而不是经元素分析确认的最终化学式。
- 原始 INS 的 SHELXT 注释给出 Flack `x = 0.413(2)`，提示可能存在明显反演孪晶；本次最终 CIF 未精修 Flack/孪晶分数，故绝对结构与孪晶比例尚不能作为最终结论。
