# 精修总结

## 最终结果

官方 SHELXT 已成功解决该大体积三斜结构，随后在 CrystalPilot 节点链中完成建模、各向异性精修、加氢、权重收敛、SHELXL 独立复核和 checkCIF。最终模型位于节点 n0044，空间群为 **P -1**，化学式为 **C44H55LaN8NiP2**，其中主配合物/晶格客体写作 **C38H49LaN8NiP2 · C6H6**。

- 晶胞：a = 10.1554(17) Å，b = 12.707(2) Å，c = 20.801(4) Å；α = 107.691(3)°，β = 100.315(3)°，γ = 96.233(2)°；V = 2477.7(8) Å³，Z = 2。
- 最终 SHELXL：R1(obs) = 0.0686，R1(all) = 0.0753，wR2(all) = 0.2212，GooF = 1.112；10450/12112 个反射满足 I > 2σ(I)。
- 差值密度：+1.576 / −1.572 e Å⁻³，rms = 0.118 e Å⁻³；没有可被可靠赋予新原子的孤立峰，也没有 ghost-atom 警报。
- 最终权重：WGHT 0.0924 8.3125；SHELXL check 与节点指标一致，最大 shift/s.u. = 0.001。
- 自动验证置信度为 90.5/100。checkCIF 为 6A/3B/13C/28G；所有 A/B/C 已在 `VALIDATION.md` 逐条解释，现存 A 级均为数据完整度或实验元数据问题，不是结构性 A 级警报。

## 求解与空间群

在任务目录的 `shelxt_work/` 中分别以中心对称和非中心对称晶格假设运行官方 SHELXT。两次均将 Laue 群判为 -1 并选择 P -1；最佳候选的 SHELXT 指标为 R1 = 0.130、Rweak = 0.016、CFOM = 0.8715，找到 C44N8P2NiLa 的非氢框架。SHELXT 没有提出不同晶胞 setting。后续对称性审计也未发现遗漏的高对称操作，因此保留 P -1。

## 关键模型判断

1. **孪晶假设被检验但未采纳。** 已将给定 HKLF5 的指数基底与当前 HKLF4 精确对应，变换为 `h5 = −h4, k5 = −k4, l5 = h4 + k4 + l4`。HKLF5/BASF 试精修得到 BASF = 0.00875，R1 仅为 0.0710，未形成有意义改善。最终 FCF 中 Fc² 对每个 hkl 单值，弱/中强度档也无典型漏建孪晶畴偏差，故最终采用普通 HKLF4 单组分模型。
2. **晶格苯无序候选被否决。** 根据局部差值峰建立双取向模型，精修占有率约为 0.627/0.373；无氢对照从 R1/wR2 = 0.0730/0.2574 变差至 0.0733/0.2588，因此回滚。数据支持“存在运动/无序”，但不足以支持明确的第二取向。
3. **晶格苯保留为离散分子。** 其六元环密度仍可辨认，因此没有使用 solvent mask，也没有与掩膜重复计算电子数。高 Ueq 和未解析运动作为未解决问题披露。
4. **氢原子按骑乘模型加入。** 芳香碳重新按 sp² 几何判定，避免把苯环碳误作 CH2；没有在缺乏差值峰证据时盲加 O/N–H。
5. **化学合理性优先。** 未为降低 R 值删除有密度支持的原子、任意 OMIT 反射或强行加入次组分。

## Restraint 说明

最终模型只对高热运动的独立晶格苯使用以下 restraint；主配合物没有几何 restraint：

- DFIX 1.390(10) Å：C28–C40、C40–C42、C42–C34、C34–C39、C39–C43、C43–C28。理由是自由精修时该环因高 Ueq/未解析运动产生不合理短键，而双取向模型没有得到数据支持。
- FLAT 0.01：C28/C40/C42/C34/C39/C43。理由是维持苯环化学上合理的平面性，避免在弱密度中出现无意义翘曲。

施加后六条 C–C 键约为 1.360–1.379 Å，原 PLAT331 A 级警报降为 C 级。约束及其影响已完整写入 CIF/RES 和验证报告。

## 代表性几何

- La1–N：2.453(5)、2.463(5)、2.539(5) Å。
- La1–Ni1：2.8163(8) Å。
- Ni1–N8：1.870(7) Å；Ni1–C4：1.992(7) Å。
- Ni1–P：2.1946(18)、2.1995(17) Å。

这些距离支持 La/Ni/P 配位核心的化学归属；柔性烷基和晶格苯的精细键长不应被过度解读。

## 数据限制与未解决问题

- `theta_full` 完整度为 0.907，到最高角的总体完整度仅 0.741；没有为压低 R 值而主观截断数据。改善需要补采倒易空间，最好使用低温数据。
- 输入 HKLF4 已完全合并，无重复反射，因此无法从现有文件恢复真实 R_int；需从 SAINT/TWINABS 缩放报告或未合并数据补录。
- 晶格苯有明显动态/取向无序，但双取向模型不受数据支持；最终作为受约束的单一离散苯保留。
- 最终残余峰约 ±1.6 e Å⁻³，未形成具有可靠化学身份的新原子位点。
- 缺少晶胞测定反射数与 θ 范围、晶体颜色/形貌/三轴尺寸、确切吸收校正类型与 Tmin/Tmax。CIF 中均如实保留为 `?`。
- CIF 中的 293 K 来自输入/程序默认值，尚未由实验记录确认；投稿前必须核实。
- PLAT995 表明 PLATON 无法由 CIF 内嵌 RES/HKL 重建 FCF，但独立 `final.fcf` 的 R1 与 SHELXL 完全一致且未使用溶剂掩膜；应随稿提交 `final.fcf`。
