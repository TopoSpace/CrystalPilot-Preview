# final.cif 本地 PLATON checkCIF 说明

验证对象：`CrystalPilot Results/task_20260829_085005/final.cif`。最终结果为 1 A、1 B、13 C、37 G。首轮的 8 A、2 B、25 C 中，已用原始 CIF 的真实元数据补齐晶胞测定统计/晶胞 s.u./化学式与计算程序，并为 C15/C16 两构象写明 disorder group；同时从显式几何表删除了 A/B 构象间不可能同时存在的伪键、伪角和伪扭角。以下逐条说明全部 A/B/C 警报。

### A 080 Maximum Shift/Error ............................ 3.50 Why ?

- 含义：末轮最大参数位移/标准不确定度为 3.50，模型未达到常规收敛判据。
- 本结构中的原因：CIF 没有内嵌原始 `.res`；atom-loop 重建丢失了无序 PART/FVAR、ADP 约束、25 条 restraint 和骑乘 H。为生成 ACTA CIF 所需的最小 SHELXL 作业只能在 302 参数/0 restraint 模型上跑 1 周期（`L.S. 0` 与 ACTA 不兼容）。
- 已做的检查/尝试：另建 n0002 跑 10 周期无约束 SHELXL；R1 由 0.0933 变为 0.0942，低占位无序 H 的位置/Uiso 失稳，故没有用“数值收敛”替换化学上更可信的沉积模型。自动骑乘 H 分支也因无序乙基 H 无法重建而被否决。
- 影响评估：这是 A 级、阻断发表级重新精修；final.cif 可用于独立诊断和复现边界，不应被视为新发表精修。消除它需要原始 `.res/.ins` 与完整孪晶数据模型。

### B 995 Can not Recreate .fcf from Embedded .res & .hkl ! Check

- 含义：PLATON 用 CIF 内嵌的单畴 `.res` 和 HKLF4 不能重算出随附 FCF。
- 本结构中的原因：不是溶剂掩膜。化合物在原文标题中明确为 non-merohedral twin；沉积 FCF 的 2,315/3,046 个重复 hkl 组具有不恒定的逐观测 Fc²。例：canonical hkl=(-4,2,1) 的 Fc² 为 2493.07 和 2074.49。FCF→HKLF4 只留下 Fo²/σ，丢失逐观测孪晶复合 Fc²/分量模型。
- 已做的检查/尝试：沉积 FCF 直接重算 R1(Fo²>2σ)=0.0525847；同一 Fo²/σ 经 SHELXL 单畴重算 Fc 后 R1(all)=0.0976。对称审计和度量学 twin-law 建议均无其他候选。
- 影响评估：对“发表 R 可由 FCF 核对”无影响，但使“从 HKLF4 重新精修复现发表 R”不可能。需原始帧/HKLF5 分量号、孪晶矩阵及域比例才能消除。

### C 084 High wR2 Value (should be < 0.25) ............... 0.28 Report

- 含义：wR2=0.2806 偏高。
- 本结构中的原因：派生 HKLF4 缺少非merohedral 孪晶逐观测模型，且原权重/约束不能完整复原。
- 已做的检查/尝试：自由精修、骑乘 H、对称性和度量学孪晶候选均已检验；没有证据支持改原子种类或补原子。
- 影响评估：反映数据模型不匹配，不等同于分子骨架错误；限制当前 HKLF4 精修数值的发表可信度。

### C 085 SHELXL Default Weighting Scheme is not Optimized Please Check

- 含义：当前重建作业的 WGHT 未优化。
- 本结构中的原因：CIF 报告原方案为 0.0935/0.0632，但对应的是未披露的孪晶/218 参数/25 restraint 模型；套在当前单畴 302 参数模型上没有相同统计意义。
- 已做的检查/尝试：检查了强度分组与 GooF；没有仅为把 GooF 调成 1 而优化权重，因为这会掩盖已证实的系统数据模型错误。
- 影响评估：wR2/GooF 不宜与论文直接比较；R1 与 FCF 审计结论不依赖此权重选择。

### C 087 Unsatisfactory S value (Too High) .............. 2.31 Check

- 含义：GooF=2.305，残差相对 σ 明显过大。
- 本结构中的原因：同 B 995/C 084；HKLF4 的 σ 很小，但逐观测孪晶 Fc 模型已丢失。
- 已做的检查/尝试：SHELXL 列表确认 10,410 行合并为 3,046 个独立反射，R_int=0.0822；没有用任意增大 σ/权重来压低 S。
- 影响评估：主要限制参数 s.u. 与拟合统计解释，不支持把结构重新宣称为发表级收敛模型。

### C 222 NonSolvent resd 1 H Uiso(max)/Uiso(min) Range 6.0 Ratio

- 含义：同一残基 H 的 Uiso 跨度异常大。
- 本结构中的原因：原文为约束 H，但 atom-loop 导入不含 AFIX；0.357 占位的乙基 H 尤其不稳定，最终 CIF 中约为 0.03–0.18 Å²。
- 已做的检查/尝试：自动重建骑乘 H 时工具因 A/B 位点重叠拒绝了 10 个乙基 H，留下不完整 C16H9 模型且 R1=0.1010，故回滚。
- 影响评估：不改变重原子骨架，限制无序乙基 H 的位置和热参数可信度。需原 `.res` 的 PART/AFIX 才能修复。

### C 230 Hirshfeld Test Diff for O2--N1 ................. 6.5 s.u.

- 含义：N1—O2 键方向上两原子的 ADP 分量差异偏大。
- 本结构中的原因：295 K 下硝基 O 原子位移参数较大；O2—N1=1.204 Å、O1—N1=1.221 Å，几何仍符合硝基。
- 已做的检查/尝试：元素归属、键长、差值图和对称性均已核查；O/N 附近无强残余峰。未在不知道原 25 条 restraint 的情况下猜加 DELU/RIGU。
- 影响评估：局部 ADP 精度警报，不支持改元素或改连接；对分子身份影响小。

### C 245 U(iso) H15C Smaller than U(eq) C15B by 0.038 Å²

- 含义：minor 构象 H15C 的 Uiso 小于载体 C15B。
- 本结构中的原因：导入丢失该 0.357 占位构象的骑乘 Uiso 关系。
- 已做的检查/尝试：骑乘 H 自动重建因构象重叠失败；未手工编造 AFIX。
- 影响评估：只影响低占位 H 的热参数；需原始 PART/AFIX 修复。

### C 245 U(iso) H15D Smaller than U(eq) C15B by 0.048 Å²

- 含义：minor 构象 H15D 的 Uiso 小于载体 C15B。
- 本结构中的原因：同 H15C，原骑乘约束未沉积。
- 已做的检查/尝试：核对 C15B 占位 0.357 与本构象 C—H 几何；没有删除该 H 来降警报。
- 影响评估：局限于低占位 H；不影响重原子模型。

### C 245 U(iso) H16D Smaller than U(eq) C16B by 0.030 Å²

- 含义：minor 构象 H16D 的 Uiso 小于载体 C16B。
- 本结构中的原因：同属缺失 AFIX 的 0.357 占位末端甲基。
- 已做的检查/尝试：保留沉积 H 坐标/占位；自由精修使同组 H 更不稳定，已否决。
- 影响评估：末端无序 H 不可靠；C15B—C16B 重原子连接仍由沉积模型支持。

### C 414 Short Intra D-H..H-X H2..H6A ................. 1.96 Å

- 含义：分子内 H2···H6A 接触较短。
- 本结构中的原因：H2 位于酰胺 N2，H6A 位于邻位芳香 C；这是邻位拥挤且 H 坐标约束信息丢失后的几何结果。
- 已做的检查/尝试：N2—H2 和芳环连接均已核查，差值图没有支持换连接或删 H 的证据。
- 影响评估：提示 H 位置精度有限；对重原子构型和分子连接影响小。

### C 722 Angle Calc 101.00, Rep 99(10), Dev 2.00 Degree

- 含义：PLATON 重算角与 CIF 显式几何表相差 2°。
- 本结构中的原因：相关条目位于 C15/C16 低占位无序乙基 H 区，H 的 e.s.d. 约 10°且原 PART/AFIX 缺失。
- 已做的检查/尝试：已删除所有明确的 A/B 跨构象伪几何；保留本条低显著性条目以披露残余不一致。
- 影响评估：不影响重原子连接；只限制无序 H 几何表的可用性。

### C 722 Angle Calc 48.00, Rep 50(10), Dev 2.00 Degree

- 已做的检查/尝试：同上一条；没有用任意几何 restraint 改动沉积坐标。
- 影响评估：低显著性局部 H 几何差异。

### C 722 Angle Calc 86.00, Rep 84(10), Dev 2.00 Degree

- 含义：同上，差 2°。
- 本结构中的原因：同属 C15/C16 无序区的高 e.s.d. H 角度。
- 已做的检查/尝试：同上；A/B disorder group 已在 CIF 明确标注。
- 影响评估：不影响分子骨架，只说明显式 H 几何表不能作为高精度数据使用。

### C 722 Angle Calc 108.00, Rep 106(10), Dev 2.00 Degree

- 含义：同上，差 2°。

- 已做的检查/尝试：本构象 C—C/O—C 重原子距离已核查；未强加未披露 restraint。
- 影响评估：低显著性 H 几何警报；不改变结构身份。
