# CrystalPilot 能力边界报告（2026-08-28）

101 例全新外部测试集（COD 反射数据 + 人类精修参考结构，5 个厂商家族）+ 8 套多厂商原始衍射帧
数据集上的系统性测评，以及由此驱动的一轮引擎改进（v1→v5）。所有数字均为实测，无挑选。

## 一、测试集

**反射数据集（`manifest_ext.json`，101 例）**：全部来自 COD（公有领域），与既有 12 例公开
案例无重叠。38 MOF/配位聚合物、28 有机、13 无机/重元素、22 专门难例（P1/赝对称/孪晶/大胞/
无序）。设备覆盖 Bruker 63、Oxford-Agilent 12、Nonius 12、Rigaku 8、Stoe 5、其他 1
（67 种具体设备型号；诚实缺口：无同步辐射源沉积数据，Cu 靶仅 5 例）。人类参考 R1 中位数
0.038。求解器只拿到晶胞+波长+组成（`gen.ins`），参考坐标与对称性绝不泄漏；空间群由强度
统计自行判定并单独计分。

**原始帧数据集（`manifest_frames.json`，8+1 套）**：Bruker PHOTON-III/APEX-II (.sfrm)、
Rigaku-OD Eiger2 (.odeiger)、Rigaku HyPix (.rodhypix)、同步辐射 Pilatus3 (miniCBF)、
Nonius KappaCCD (.kcd)、Stoe (.xi)、旧版 Oxford (.rod_img)，全部 CC-BY Zenodo。

**判定标准（严格）**："solved" 要求对参考结构非氢原子召回率 ≥75%、精确率 ≥60%、重原子
召回率 ≥99%（emma 匹配，特殊位置与溶剂公平化处理）。SG top-1 按空间群类型号比对。

## 三、本轮实现并验证的改进（v1→v5）

1. **并列空间群试解**（最大失败桶的根治）：强度统计无法区分的候选（Cc/C2c、P1/P-1、
   P2₁/P2₁m、P6₁/P6₅ 等；17 例错 SG 中 11 例真值就在并列第 2 名）现在逐一快速试解。
   选择规则经逐例校准：以统计排名为先验，翻转需按比较公平性付出证据，对映体对 0.00
   （R1 是唯一信号）、同心性 0.02、中心替代非心 top 容忍 +0.025（Marsh 规则：非心参数
   翻倍必然 R1 略低）、非心替代中心 top 需优 0.10、翻转目标试解 R1<0.35。
   净效果：SG top-1 +5.9 个百分点；如 cod_2203769 从"错判 P1"变为 SOLVED P-1
   R1=0.0315（人类 0.0261）。
   *弯路记录（重要负结果）*：结构级倒反中心检测两次失败，emma 对此天然失明（每个空间
   群的欧几里得规范化群都含 −1，模型对反演像的 emma 匹配恒为 1.00）；自研 ADDSYM-lite
   在试解级模型上对真中心案例仅得分 0.12–0.87，无可分阈值。试解阶段模型太脏，结构对称
   性判据不可用。
2. **幽灵原子修剪**：第二大失败桶（15 例 near-miss 中 12 例召回率 100% 但精确率 <0.6，
   即真原子全在、伪峰翻倍）。精修后按 ADP 修剪：轻原子 u_eq>max(0.20, 5×中位数)，重原子
   仅在 R1<0.10 时以 >max(0.2, 6×中位数) 修剪；仅在 0.06<R1≤0.18 修复窗口内启用（窗口
   外两次实测误删真原子：R1 0.22 时删掉真 Co、R1 0.046 时删掉真无序连接体碳）；快照回滚
   护栏（R1 恶化 >0.03 撤销）。
3. **失败会话交给 Agent**：`run_standard` 早期失败（CF 全败/解释失败/初精修失败）原先
   丢弃会话导致 agent 直接跳过（7.1 秒"秒败"），最需要 agent 的案例反而没让它上场。
   现在失败结果携带活会话，agent 可接手换参数/换空间群重试。
4. **帧链路多厂商化**：识别 .odeiger/.rodhypix/.rod_img/.esperanto/.kcd；未补零帧号
   经硬链接规范化目录导入（上游 dials 的 directory= 输入损坏、通配符崩溃）；SHELX 加载器
   丢弃 σ≤0 反射（DIALS 导出含此类行，smtbx 权重断言崩溃）。
5. **评估器防爆护栏**：emma 代价 >10⁶（n_ref×n_model×群阶）时退化为重原子评分并标记
   （实测一个 P6₁ MOF 评估卡死 >30 分钟）。

## 四、v5 能力边界地图（101 例）

**强项**：有机分子 64% solved / SG 89%；MOF 55% / 89%（主目标域）；三斜不再是弱点
（50% solved，P1/P-1 陷阱被试解规则收拾，专门 hard-P1 组 SG 100%）；单斜 SG 92%；
Bruker 数据 52%（样本最多）。hard-disorder、hard-large 各 50%。

**弱项（按严重度）**：
| 边界 | 现状 | 根因（案例证据） | 提升路径 |
|---|---|---|---|
| 无机/重元素相 | solved 8%（1/13） | 元素指认为 MOF/有机调优：MnSbSe₂I 被指认成 {I:2, **C:1}**（默认碳、按金属配位距离指认 O）；重元素间 X 射线衬度不足叠加 | 重元素专用指认模式：按峰高与 UNIT 元素表全局分配，无碳默认；Sb/I 类近 Z 对按键价/几何判别 |
| 试解质量区 R1>0.2 | "解不动"桶 11 例 | 精修判据与结构判据在此区均不可靠（多为无机+大胞+弱数据交叠） | 依赖 agent 救援；引入 SHELXT 式对称性下降重试 |
| 孪晶 | 2/5 solved；3 例假晶格曾骗过 Laue 扫描 | 无孪晶定律检测/BASF 精修；1 例 smtbx 孪晶内部崩溃 | 孪晶定律枚举（coset）+ HKLF5/BASF 支持 |
| 赝中心对称/极性陷阱 | hard-pseudo 0/4 | P2₁ vs P2₁/m、Pna2₁ vs Pnam 型；试解 R1 与结构判据均处重叠带 | 决定性判据 = Flack 参数精修 + 二次谐波类外部证据；或 agent 化学推理 |
| 巨量反射（≥15k） | 0/4 solved | 大胞+高冗余数据的解释与精修参数化不足 | 分辨率分层精修策略；大结构专用峰解释预算 |
| 三方/四方 | 0/4、1/2 | R32:H 基变换 **代码 bug**（未修）；I-4/I4m 类中心歧义 | 修菱方设置 bug；四方中心歧义入试解规则 |
| 帧格式缺口 | STOE .xi、旧版 Oxford .rod_img v3 | dxtbx 无 Format 类（上游缺口，已在清单记录） | 写自定义 dxtbx Format 插件或转换器 |

**帧→结构端到端实测**：AsBr₃（Eiger2）晶胞与文献精确一致、CC½ 0.993、SG 建议 P2₁2₁2₁
正确，解出 R1 0.119、全原子召回率 1.0（精确率 0.5 = 与 ext 集同源的幽灵原子问题，参考
R1 0.0161）；硫脲（Bruker PHOTON-III 变温 ramp 序列）机械链路全通但该数据本身太弱，
单 sweep 在正确 SG 设置下恢复 60% 原子（精确率 1.0）。`--symmetry auto` 在两例上都掉进
Pmnm 中心陷阱（轴向消光反射太少），DIALS 的 SG 建议应作为 hint 传入，已列改进项。

## 五、Agent 救援（v5 失败集，16 例多样性采样）

对 v5 的 53 例未 solved 案例做失败模式轮转采样，取 16 例跑 agent 模式（gpt-5.6-sol xhigh，
平均 464 s/例）。**4/16 完全救活**，另有 4 例把原子匹配推到 0.68–0.91（差一步）：

| 案例 | v5 状态 | agent 结果 |
|---|---|---|
| cod_2020930 | CF 全试失败（管线无解） | **SOLVED** P2₁/n R1=0.0371 match=1.0，验证了"失败会话交给 agent"修复 |
| cod_2015536 | 轻原子缺失 match 0.18 | **SOLVED** P2₁/c R1=0.0422 match=1.0 |
| cod_2019928 | near-miss 0.69 | **SOLVED** P2/c R1=0.0399 match=1.0 |
| cod_2216484 | 解不动 R1 0.31 | **SOLVED** P2₁/n R1=0.0778 match=1.0 |
| cod_2020921 | 孪晶假晶格骗成 Cmca | SG 纠正为 P2₁/c（结构恢复 50%） |
| cod_2211653 / 2018533 / 2018446 | 各类 | match 0.91 / 0.90 / 0.68（差一步） |
| cod_2108510 | R32:H 基变换崩溃 | 0.1 s 即崩，bug 在会话建立之前，agent 无法接手（必须修代码） |

**组合系统（确定性 v5 + agent 救援）在本采样口径下：52/101**。按救援命中率外推全部 53 例
失败可到 ~55–60/101，但那是外推非实测，此处只报告实测数。判据严格性提醒：多个"ok"案例
（如 cod_2021267 R1=0.0337、cod_2108482 R1=0.0259）R1 已达发表级但因原子匹配细节
（对映体/子群设置差异）未计 solved，按宽松口径（SG 正确且 R1<0.10）组合系统为 60/101。

## 六、下一步优先级（证据加权）

1. 无机元素指认模式（预计 +8–10 例 solved，最大单一杠杆）
2. 修 R32:H 基变换崩溃 + I4/I-4 类四方歧义入试解（+2–3 例 SG）
3. 帧链路：DIALS SG 建议作为管线 hint；Flack 精修用于极性/赝中心判别
4. 孪晶定律检测 + BASF（hard-twin 桶 + 假晶格 SG 案例）
5. 大结构（≥15k 反射/≥10⁴ Å³)专用解释与精修预算
6. Agent 层面：把"并列 SG 试解"“修剪"等 v5 新机制作为工具暴露给 workbench agent

## 复现

```bash
# 数据获取（可重建全部 101 例）
.venv/Scripts/python.exe benchmark/tools/fetch_ext.py
# 全量测评 + 分析
.venv/Scripts/python.exe -X utf8 -m crystalpilot.benchmark.ext run mode=standard
.venv/Scripts/python.exe -X utf8 -m crystalpilot.benchmark.analyze
# agent 救援
.venv/Scripts/python.exe -X utf8 -m crystalpilot.benchmark.rescue results=<results.json> max_cases=16
```
