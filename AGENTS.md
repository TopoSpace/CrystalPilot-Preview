The repository root intentionally holds no agent instructions. Each workbench
project receives its own `AGENTS.md`, generated by
`crystalpilot/workbench/agents_md.py` from the project's `knowledge_mode`
setting; the version marker sits on the first line of that file. Keep campaign
and user projects outside the repository, for example under
`H:\CrystalPilot-campaigns\<name>\`: the kernel injects every `AGENTS.md`
between the git root and the project directory, so a project inside the
repository would receive both this file and the template. Development
conventions are described in `ARCHITECTURE.md`.
