# 剩下的 R 值差在模型还是差在数据

## 为什么这是个真问题

R1 高，第一反应通常是"模型还没修好"。**r24 判例证否了这个默认假设**：
把 agent 的终模型冻结，只换数据重修，在文献数据上 R1 0.0904，与文献
自己发表的 0.0901 逐位复现，BASF 0.497 vs 0.496。也就是说那个模型是
发表级的，**0.16→0.09 的全部差距在数据还原**，继续改模型一分钱也
挣不回来。

同一批帧的五种还原，同一个模型上的 R1：

| 还原 | R1 | Rint |
|---|---|---|
| 我方 CAP（单 UB 常规 + 高冗余）| **0.0747** | 0.088 |
| 作者常规还原 | 0.0811 | 0.072 |
| 文献发表数据 | 0.0904 | 0.104 |
| CAP twin 解卷积 HKLF5 | 0.0977 | — |
| 我方 DIALS | 0.1625 | 0.381 |

**同一个模型，R1 相差 0.09。** 还原质量的量级可以远大于建模水平的
量级，这一条值得先记住，再谈别的。

## 判据（一条都不是阈值，是证据）

**指向数据端的信号**（越多条同时成立，越应该先修数据）：

- **Rint 与 R1 同量级或更高**。Rint 0.34 的数据上要求 R1 0.05 是不
  讲理的：合并残差已经把上限定在那儿了。反过来 Rint 0.07 而 R1 0.16
  说明数据不是瓶颈。
- **模型在化学上已经讲得通**：连接完整、配位球合理、无幽灵原子、
  ADP 无系统性异常、差值图上没有成规模的可解释残余。这时 R 还高，
  几乎一定不在模型。
- **壳层曲线塌得早**（estimate_resolution）：CC½ 在远高于当前截断处
  就掉下去，或完整度先崩。灌了噪声壳层的数据会同时抬高 R 和 Ueq。
- **没有像样的吸收校正**：重原子 + 大晶体 + 无 analytical/multi-scan
  记录 = 系统误差直接进 R。r24 的差距主因就是这一条加截断纪律。
- **冗余低**：冗余 3 与冗余 17 对离群剔除的容忍度完全不同。高冗余
  能把重叠污染当离群清洗掉（CAP 单 UB 胜显式解卷积的机制）。

**指向模型端的信号**：

- 差值图上有**成形状**的残余（配体片段轮廓、环、明确的球），那是
  没建完的东西，不是噪声。
- 特定原子的 ADP 反常（拉长、NPD、与邻居量级不符），局部建模问题。
- 换引擎结论一致：run_shelxl 与 run_olex2 给出同一个 R（差 <0.01），
  说明不是精修实现的问题，模型确实只能拟合到这里。
- 对称性/孪晶/组成假设可能整个错，这类"模型错"表现为 R 卡住不动
  且改什么都不动，需要回到 check_symmetry / audit_reflection_data /
  ncs_audit 重审，而不是继续微调。

## 能做的实验（不用参考答案）

1. **换引擎**（run_olex2）：排除"是不是精修器的问题"。差 >0.01 才
   值得深究。
2. **换截断**（set_resolution_limit + 重修）：如果截到壳层曲线塌之前
   R 明显改善而模型不变，说明之前在拟合噪声。**记录理由，不要为了
   好看的 R 去截**：截断是数据判断，不是修饰手段。
3. **换还原**（reduce_with_crysalis 产出另一套 hkl → swap_reflection_data
   换进来，模型不动重修）。这是**平台内的模型移植判决法**：模型是
   常量，数据是变量，R 的变化就是数据端的贡献。厂商实验目录可用时
   这是最有力的一招。
4. **看吸收校正记录**：ingest_vendor_data 会把 .abs / .cif_od 的
   T_min/T_max 与校正类型摄入；槽位是空的就说明这一环没做过。

## 怎么写进报告

数据端受限时，**把证据摆出来比硬凑 R 值有价值**：写清 Rint、冗余、
壳层统计、吸收校正状态、截断依据，说明模型已到数据允许的程度。
审稿人接受"数据限制"，不接受没有依据的低 R。相关卡：
reflection-audit-reading（体检怎么读）、cap-listen-reduction（第二条
还原路线）、hklf5-twin-workflow（孪晶数据的移植判决判例）。
