# CrystalPilot 工作台更新

本分支整合 Linux 运行适配和会话界面优化，保留原有结构查看、分析、节点、指标、验证与产物功能。

## 会话与科研记录

- 工具和命令采用轻量单行摘要，按需展开原始输入与结果。科研关键调用的成功结果也会保留，普通辅助操作可归纳折叠。
- 求解、精修、寻峰、指标化、积分、密度、验证、编辑等操作使用统一线宽、按用途区分的图标。
- 运行中的调用文字使用柔和流光，完成后停止；不显示单项运行时长。错误采用小标记和中性色提示。
- 用户消息可复制；助手只在最终回复下显示复制按钮。展开箭头跟随文字末尾，消息和连续调用的间距保持紧凑。
- 模型文本通过本地短缓冲以稳定节奏逐步淡入，边接收边显示。完成事件不会直接跳出全部剩余文字；缓冲耗尽时等待新内容。
- Markdown 解析与逐帧播放分开，保留链接、表格、代码和问题卡。历史内容不重播，减少动态效果设置直接显示内容。
- 本回合全部文字播放和淡入结束后，才显示底部“已完成”。向上阅读、加载历史和中断时保留内容及阅读位置。

## 导航与设置

两侧栏使用非线性展开/收起动画，支持连续反向切换、窄屏抽屉和无延迟拖动调整宽度。侧栏控制不遮挡标题，项目选择弹窗使用独立显示层。

设置支持模型搜索、提供方管理、主题与字号，以及服务器目录浏览；选择 CIF 后浏览目标目录不会丢失已选文件。

设置 → 外观 → 展示模式可自定义左上角名称。关闭或留空时恢复 CrystalPilot，偏好保存在当前浏览器。版权文字在输入框正下方居中显示。

## 自动标题

只有新建且尚未命名的会话会申请一次模型命名，使用首次发送时选择的模型及提供方。标题优先保留样品、数据集编号或文件名，再说明求解、精修、验证任务。

历史会话、手动命名、已自动命名或已申请过命名的会话，不会因继续聊天、刷新、切换模型或重启再次请求命名。手动改名始终优先；失败时保留数据相关的本地标题，不自动重试或更换模型。

## 运行适配

Linux 使用项目内 Python、Codex 与科学程序路径；修正 DIALS 子进程环境、大小写敏感路径、MCP 冷启动和管道断开回收，并兼容原生 SHELX/PLATON 输出。科研结果保留完整的有界 JSON 摘要，避免截断或非有限数值妨碍前端读取。

安装和启动方式见 [Linux 安装说明](INSTALL-LINUX.md)。部署凭据、机器配置、授权程序和实验数据不随本分支的源码修改发布。
