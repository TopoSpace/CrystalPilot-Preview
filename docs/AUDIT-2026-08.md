## 3. Skill 层（本轮落地）

**原则：工具算事实，技能管判断。** 外部专家知识一律进技能库，不进代码。

- 形态：`knowledge/**/*.md`，frontmatter（description/alerts/tools/tags/
  source/confidence/created_by）+ 正文（规则、数值链、逐条出处）。
  旧 expert-cases 卡片 schema 兼容解析，6 卡 + disorder-ruleset（72 条）
  零改动纳入。
- 工具：list_skills（警报码/工具名/关键词检索）、read_skill、save_skill
  （强制出处+理由+confidence；slug/正文门；跨类目原位更新）、delete_skill
  （限 knowledge/ 树、要理由）。写路径=MCP 进程（引擎目录），codex 沙箱
  写不到，权限分界天然成立；specialist 子代理只读。
- 集成：run_checkcif 的 A/B 警报自动附 related_skills；AGENTS v18 技能库
  节（检索起手 + save 纪律：只存跨项目可复用判断、必须带出处、不存项目
  事实与未验证猜想 + 与数据冲突时以数据为准并把反例写回技能）。
- 动态性：保存即生效（文件层，无需重启/改码），git 留全史。
- 首条战役沉淀技能已由工具自举写入：delivery-self-audit（三方守恒审计，
  770 战役两次拦截静默丢原子）。
