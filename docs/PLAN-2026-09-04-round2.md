## 0. 一页结论

1. **系统骨架已经是"Codex 内化"的形态，不是拼接**：69+1 个 MCP 工具按 MUTATING/READ_ONLY/SESSIONLESS 三套能力集合受守卫测试保护；审批走 Codex elicitation（4 档权限模式各自映射 MCP approval_mode + sandbox）；每次成功的改模型调用自动提交为节点（`nodes/nXXXX/model.res|cif|node.json|peaks.json|f_mask.pkl`），分支/检出/回滚/最佳节点对账都在工具层；交付有 `write_outputs → run_checkcif → finalize_delivery` 三段门禁与 MANIFEST 哈希。**这一层本轮不推倒，只补齐与打磨。**
2. **本轮最大的功能缺口在师兄清单**：π–π、C–H···π/O/F、卤键、拓扑、互穿、形状、孔径/孔道维度**零代码**；氢键层只看 D···A 距离、不看氢、不判供受体、无对称码、无 PART 意识；短接触层主动**排除所有氢原子**却在提示里写着"π-π 堆积、卤键"；孔道等值面在"生长"视图不扩展，密度图与 Q 峰在超胞下只画原胞；五套互不一致的成键判据并存。**还有一个已上线的算错**：贯穿型孔道的孔心坐标落在晶胞外（六个真实项目全部命中，D17），查看器和引用都在用这个数。**先立"一份成键真值"，再在其上做相互作用/孔道/拓扑，所有数值配判据来源、可交叉核对；D17 在 R3 第一步修并公告。**
3. **视觉问题有数据**：浅色第三级文字 `#9c9ca3` 对白底 2.73:1（AA 要 4.5），强调色 4.21、成功/警告色 3.3；深色第三级 3.89；字号压到 7–9 px；右栏控件区允许占 45% 高度，3D 画布被压在底下，"结构不是视觉主体"是布局写死的。方案：Anthropic 式暖中性色板（已算过对比度全部 ≥4.5）、最小字号 11 px + 可调档位、画布 flex-1 主体、控件收成画布上的浮动工具条、Olex2 语义的生长菜单。
4. **线上跑的前端是 9 月 2 日的旧构建**（`ui/dist` 09-02 00:22；`toolCards.tsx` 09-04 07:12 改过），最近两天的工具卡没进服务。R0 先重建并加"构建指纹"防再犯。

## 2. 本轮设计原则

1. **判断力 > 阈值**：所有分析输出分三段，测量值（带对称码/网格误差）、所用判据（带来源与默认值）、解读（明确标为解读）；不给单一"判词"。
2. **一份真值，多处消费**：成键/金属判定只在 `chem/bonding.py` 一处定义，查看器、`get_geometry`、`validate_structure`、`structviews`、前端全部消费同一份（前端收服务端给的 `is_metal`/`bond.kind`，删掉 `NON_METALS` 名单）。
3. **范围自适应是场景契约**：场景响应带 `range`（实例化原子的分数坐标包围盒 + 覆盖它的晶格平移 `tiles`），所有"按胞算"的产物（孔道、密度图、Q 峰、对称元素）由客户端按 `tiles` 平铺；所有"按原子对算"的产物（氢键、π–π、接触）直接在实例集上算。
4. **不为测试晶体特化**：判据用元素通用规则（cctbx 共价/vdW 半径表），验证用合成晶体（MOF/有机/盐/有机金属各一）+ 真实项目直跑 + 第三方交叉核对（PLATON 601/602、Olex2 headless `htab`/`pipi`）。
5. **UI 永不直接改节点库**：装配/检出/回滚仍是"预填输入框 → agent 用工具执行"；查看器只读。
6. **每一步可回滚**：每轮起止打 tag（`r2-pre-r1`…），前端改动伴随 `npm run build` + 服务器重启核对监听 PID；构建指纹进界面。
7. **资源节制**：4 核 BelowNormal；跑 CrystalPilot 解析的实验只在 R5、R7 各一格；副线子代理最多 2 个并行 worktree，只用 Opus/Sonnet。

## 7. 风险与能力边界（如实）

- 相互作用判据是约定而非真理，不同软件默认不同 → 输出永远带判据与来源，提供 PLATON/Olex2 两档预设；不下"结论"。
- 网格法孔径与 Zeo++（Voronoi）有系统差 → 报网格步长与误差，文档标"网格法"。
- 拓扑符号依赖簇识别与 Systre；非常规 SBU 可能简化错 → 简化网必须画出来供人核对，附 `confidence`。
- 20 000 原子场景的相互作用计算与平铺有性能上限 → 上限 + 截断药丸 + 预热缓存。
- 模板预算/规格缓存/服务器重启/Windows cctbx 主线程等平台坑已有记录，按记忆里的检查单执行。
- 子代理成本高（r23 1.7 M tokens）→ 默认关；实验只一格。
