## 1. 已实现

### 1.1 检查结果有明确来源

- 新节点记录递增的 `revision`；历史节点缺该字段时保持未知，不补造数字。
- 每次 `write_outputs` 生成新的 `delivery_revision`。checkCIF 记录提交时的目标文件、节点、修订号与交付版本，而不是事后借用当前节点。
- 在检查期间发生重新导出，旧检查仍绑定旧版本，不能用于新版本的定稿。
- `MANIFEST.json` 现在是文件名/大小和来源版本清单，不再生成内容摘要。
- 验证侧栏区分当前查看节点、其他节点、已更新的交付版本和来源未知；引用绑定报告自己的节点，可跳回来源节点。
- 构建信息只显示应用版本与时间，不再读取或比较提交指纹。

**边界：** 这是应用管理的来源关联，不是对任意手工覆盖文件的完整性证明。手工改过模型或数据，应显式重新导入/导出并重新进行适用的科学检查。完整反射数据版本快照和跨进程单写者事务仍在下一阶段。

### 1.2 分析不再等最慢一项全部完成

分析拆成相互作用、拓扑/形状、客体、孔道四个阶段，快速结果先返回。

- 后台单工作线程、同项目/节点共享任务、有界排队与结果保留。
- 每个阶段分别显示等待、计算中、就绪、失败、不支持或取消；缺失结果是 `null`，不会被写成“0 个孔道”或“没有相互作用”。
- 条件轮询只更新变化的结果；等待孔道时不反复复制、传输整张结果表。
- 关闭页面只释放本窗口的观察者；显式停止操作也不会误停另一个窗口仍在使用的任务。
- 正在执行的底层 C 计算不能立即终止，界面明确说明；停止后不再开始后续阶段。
- 简化网图层读取已就绪的拓扑，不再等待整个孔道产品返回。
- 原有同步 `analyze_packing` 继续可用，能保留成功的请求块，明确返回失败/不支持部分。

分析页默认保留上方晶体视图，用户可以收起；早期页签点击现在保存在 URL，不会在项目初始化后丢失。

**实测口径：** 真实 MOF（ka1-hex，n0041）约 3.11s 出现首项结果，约 7.84s 拓扑已就绪，13.64s 全部返回。本次孔道读取了已有缓存（该阶段约0.032s），所以不能据此声称此前约118s的孔道冷计算本身已提速。本轮改善的是结果到达顺序和交互等待；数值内核性能优化仍需单独测量。

### 1.3 没有 HKL 也能分析 CIF

打开项目对话框新增“仅查看 CIF”：选择真实 CIF，指定仓库外的新项目目录；多结构 CIF 可指定数据块。

- 新节点以所选 `model.cif` 数据块为规范模型，不要求转换为 RES。
- 保留原始标签及大小写、长标签、明确的空间群操作、非原点反心设置、ADP 和无序组信息。
- 旧的 RES 规范节点仍按其 `canonical_model` 读取，不能把旧的派生查看 CIF 错当成规范模型而丢失 PART。
- 支持结构显示、grow/pack、几何、相互作用、拓扑与几何孔道；默认只读权限且关闭委派。
- 当前 R1/wR2/GooF 不伪造。源 CIF 报告的指标单独折叠为“源 CIF 报告的指标（未重新精修）”。
- 没有关联观测反射时，密度图、Q 峰、精修和残余电子数不可用；几何孔道体积/孔径仍可计算，电子数保持未知。
- 缺失 ADP 不显示成 Ueq=0，也不产生“位移过小”的虚假警告；查看器、引用与 MCP 原子表保持同一含义。
- 需要精修时必须显式导入真实反射数据，再进入正常精修流程。不会制造占位 HKL 来绕过前提。

## 2. 接口

```text
POST /api/projects/import-structure
  multipart: project, file, block（可选）

POST /api/wb/refine/analysis/jobs
  JSON: project, node, observer_id（可选）
GET /api/wb/refine/analysis/jobs/{job_id}
  query: project, since_result_revision（可选）
POST /api/wb/refine/analysis/jobs/{job_id}/cancel
POST /api/wb/refine/analysis/jobs/{job_id}/release
  JSON: project, observer_id

GET /api/wb/refine/validation-source
  query: project, cif
```

`start` 返回观察者标识；后续轮询不新增观察者。`result=null` 在条件轮询里代表结果未变化，客户端保留上一份结果，并更新阶段状态。它不同于某个阶段自身的 `pores=null`（没有可用结果）。

Python 入口：

```python
RefineProject.create_structure_only(project_dir, cif_path, block_name=None)
project_mode_info(project_dir, ref=None)
```

后者只读取持久化元数据，不重新合并衍射数据。项目指令更新为 v38（纯工具变体 v4），明确结构只读边界与本轮操作约束。

## 4. 使用与回滚

1. 从“打开项目 → 仅查看 CIF”开始纯结构分析；普通衍射项目继续走原入口。
2. 点击“分析”，先阅读已经就绪的部分；其余阶段在后台继续。可保留/收起结构视图。
3. 不把源 CIF 的文献指标当成本次计算结果，不把未知 ADP/电子数当作零。
4. 检查后重新导出会产生新版本，旧检查不能代替新版本检查。
5. 软件变更分批提交。回滚选定提交后重建前端，并在无活动模型回合时重启服务；晶体节点历史与软件回滚是两层，不能互相替代。
